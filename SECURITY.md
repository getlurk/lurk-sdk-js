# Security

Please report a vulnerability to **security@getlurk.com**, or privately through this repository's **Security** tab ("Report a vulnerability").
Do not open a public issue for it. We acknowledge within 2 business days.

This SDK is **generated** from Lurk's API description and released as a snapshot; a fix ships as a patch release of the latest version.
Only the latest major version is supported.

Never put a Lurk secret key (`lurk_sk_…`) or a webhook secret in an issue, a log or a screenshot. If you did, revoke it in the dashboard first.
