# Contributing

This repository is **generated** from Lurk's private monorepo and is overwritten on each release, so a pull request cannot be merged here.

- **Found a bug, or something confusing?** Open an issue. Say the SDK version, your runtime, what you did and the `request_id` from the error. Never include a key.
- **Have a fix?** You are welcome to open a pull request as a way of showing us the change. A maintainer applies it upstream, with you credited as
  co-author, and it arrives in the next release; we close the pull request with a link to that release.
- **Sign your commits off** (`git commit -s`): by doing so you certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/).
  This SDK is licensed under Apache-2.0 and we do not ask for a separate agreement.
- **Security problems** go to security@getlurk.com, not here (see SECURITY.md).
